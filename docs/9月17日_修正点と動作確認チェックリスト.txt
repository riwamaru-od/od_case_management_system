案件管理・見積書自動作成システム　9月17日 修正点と動作確認チェックリスト
==========================================================================

このチェックリストは、9月17日に実施した修正の内容と、その動作確認手順を
まとめたものです。上から順に実施してください。

チェック欄の見方
  [ ] … 未確認
  [x] … 確認済み・問題なし
  [!] … 問題あり（内容を余白にメモしてください）

今回の修正は3点です。
  1. 請求を出した後でも再見積もり（見積書の再作成）ができるようにした
     （その際、古い請求書・納品書はロックして出力できないようにする）
  2. 各テンプレートの転記先セルを変更した
  3. 取引先名を「社名（担当者名）」のプルダウンから選ぶようにした


==========================================================================
0. 事前作業（必ず最初に実施してください）
==========================================================================

今回の修正では、案件シートの列が 36列（AJ列まで）から 37列（AK列まで）に
増えています。また、テンプレートのレイアウト変更（0-5）は運用者の作業が
必要です。必ず 0-1 から順に実施してください。

[ ] 0-1. 最新のコードを反映し、Webアプリを再デプロイする
     手順: clasp push の後、「デプロイを管理」から新しいバージョンをデプロイ
     理由: 書き込み操作はWebアプリ経由で実行されるため、push だけでは
           反映されません（同じURLのまま新バージョンにしてください）

[ ] 0-2. 案件シートの列を拡張する
     手順: メニュー「管理者用メニュー」→「案件シートの構成を確認・修復する」
     期待: 完了ダイアログに以下が表示される
           ・xx期_表示、xx期_全案件DB、原本_表示、原本_全案件DB の4シート
           ・「列数を 36 → 37 へ拡張」
           ・AK列「納品書無効化日時」の見出しが追加される

[ ] 0-3. 追加された列の見出しを確認する
     期待: 表示シートは 2行目、全案件DBは 1行目 に以下が入っている
           AK列「納品書無効化日時」
     注意: 表示シートの1行目（見出しの1段目）は書き換わっていないこと

[ ] 0-4. シートの保護範囲を AK列まで広げる
     手順: 表示シート・全案件DBシートそれぞれで、保護範囲を AK列 まで拡張
     理由: 追加した列もシステムが自動で書き込む列のため

[ ] 0-5. 3つのテンプレートのレイアウトを変更する ★重要
     対象: 見積書・請求書・納品書の各テンプレート（スプレッドシート）
     手順: 下表のとおり、転記先のセルを空けておく（見出しのセルを別に
           用意する必要はありません。「案件No.17-001」のように、見出しごと
           1つのセルに書き込まれます）

       ■ 見積書テンプレート
         ・G1  → 使わなくなります（案件番号は G54 に入ります）
         ・G6  → 使わなくなります（通し番号は G53 に入ります）
         ・G54 に「案件No.{案件番号}」が入る
         ・G53 に「見積書No.{通し番号}」が入る
         ・J49 に取引先DBのP列「留意点」が入る（社内用。PDFには出ません）
         ・G12 / G13（担当社員名・メール）は変更なし

       ■ 請求書テンプレート
         ・G1  → 使わなくなります（案件番号は G54 に入ります）
         ・G6  → 使わなくなります（通し番号は G52 に入ります）
         ・G54 に「案件No.{案件番号}」が入る
         ・G52 に「請求書No.{通し番号}」が入る
         ・G11 / G12 に担当社員名・メールが入る（G12 / G13 から変更）
         ・G53（見積書No.の参照）は変更なし

       ■ 納品書テンプレート
         ・G1  → 使わなくなります（案件番号は G54 に入ります）
         ・G54 に「案件No.{案件番号}」が入る
         ・G11 / G12 に担当社員名・メールが入る（G12 / G13 から変更）
         ・G6（納品書の通し番号）、G52・G53（見積書No.・請求書No.の参照）は
           変更なし

     注意: G54・G53・G52 は PDFの出力範囲（A1:H54）の中に入ります。
           罫線・文字サイズ・折り返しの設定を整えておいてください。
           J49 は出力範囲の外のため、PDFには出ません。

[ ] 0-6. 書類の編集可能範囲が変わったことを確認する
     内容: 自動転記されるセルを手入力から守るため、G列の編集できる下端を
           変更しました（この設定は、今後作成される書類から反映されます）
           ・見積書   G22:G54 → G22:G52
           ・請求書   G22:G52 → G22:G51
           ・納品書   G22:G51（変更なし）

[ ] 0-7. 取引先名のプルダウンを生成する
     手順: メニュー「管理者用メニュー」→「取引先名の選択肢を更新する」
     期待: 「取引先名の選択肢を更新しました」と表示され、件数が出る
     確認: 「config」シートのB列に「社名（担当者名）」の一覧ができている
     注意: この操作を行うと、案件シートのB列に入力規則（プルダウン）が
           設定されます（当期の表示・全案件DBと、原本の2シート）

[ ] 0-8. 進行中の案件の取引先名を選び直す（該当する場合のみ）
     対象: すでに登録済みで、取引先名が「社名」だけになっている案件
     手順: B列のプルダウンから「社名（担当者名）」を選び直す
     理由: 社名が取引先DBに1件しか無ければそのままでも動作しますが、
           社名が重複している取引先は、書類作成時にエラーになります
           （「取引先を特定できません」）


==========================================================================
1. 請求後の再見積もり（修正内容1）
==========================================================================

請求書を出した後でも、見積書の「再作成」ができるようになりました。
その際、古い請求書・納品書は自動的にロックされ、出力できなくなります。

準備: テスト案件を1件、請求書のPDF出力・納品書の作成まで進めておく
      （請求ステータスが「請求済み」の状態）

[ ] 1-1. 請求済みでも再作成ボタンが押せること
     手順: 請求済みの案件を選択し、見積書カードの「再作成」を確認
     期待: ボタンが活性になっている（従来は非活性でした）

[ ] 1-2. 見積書を再作成できること
     手順: 見積書の「再作成」をクリック
     期待: 「見積書_最新」が作り直され、ステータスが「見積書作成中」になる
           旧版は「見積書_v{番号}_{日付}」として同じファイル内に残る

[ ] 1-3. 古い請求書がロックされること
     手順: 請求書ファイルを開き、「請求書_最新」シートのセルを編集してみる
     期待: 「保護されています」と表示され編集できない

[ ] 1-4. 古い納品書がロックされること
     手順: 納品書ファイルを開き、「納品書_最新」シートのセルを編集してみる
     期待: 編集できない

[ ] 1-5. 社印が外れること
     手順: 請求書・納品書のG4セル付近を確認
     期待: いずれも社印が除去されている（無効な書類と見分けるため）

[ ] 1-6. 古いPDFが削除されること
     手順: 請求書・納品書の案件フォルダを確認
     期待: PDFが削除されている。案件シートのL列・N列（出力リンク）も空

[ ] 1-7. 出力ボタンが押せなくなること
     手順: サイドバーの「請求書出力(PDF)」「納品書出力(PDF)」を確認
     期待: いずれも非活性。マウスを合わせると理由が表示される

[ ] 1-8. 請求ステータスが戻ること
     手順: 案件シートのH列を確認
     期待: 「未請求」に戻っている。「最終承認済み」ボタンも非活性になる

[ ] 1-9. 先に請求書だけを作り直せないこと
     手順: 1-2 の直後に、請求書カードの「再作成」を確認
     期待: 非活性（見積書が再作成・差し戻し中のため）

[ ] 1-10. 見積書を承認すると先へ進めること
     手順: 「見積書完成」→「見積書承認」→ サイドバーを確認
     期待: 請求書の「再作成」が活性になる

[ ] 1-11. 請求書を作り直せること
     手順: 請求書「再作成」→「請求書完成」→「請求書承認」
     期待: 社印が押し直され、「請求書出力(PDF)」が活性になる
           明細には、作り直した見積書の内容が転記されている

[ ] 1-12. 納品書を作り直せること
     手順: サイドバーの「納品書作成」をクリック
     期待: 納品書の新しいシートが作られ、社印が押される
           旧版は「納品書_v{番号}_{日付}」として残る
     補足: 納品書には「再作成」ボタンがありません。作り直しが必要な間だけ
           「納品書作成」ボタンが再び押せるようになります

[ ] 1-13. 出力すると請求済みへ戻ること
     手順: 請求書・納品書のPDFを出力 → 案件シートのH列を確認
     期待: 「請求済み」になり、「最終承認済み」ボタンが活性になる

[ ] 1-14. フォルダが重複していないこと
     手順: Driveの請求書フォルダ「{期}期 / 請求中案件」を確認
     期待: 同名の案件フォルダが2つできていない

[ ] 1-15. 請求書の再作成でも納品書が無効になること
     手順: 別のテスト案件で、請求書だけを「再作成」する
     期待: 納品書がロックされ、出力できなくなる（AK列に日時が入る）

2. テンプレートの転記位置変更（修正内容2）
==========================================================================

事前作業 0-5 を実施してから確認してください。

[ ] 2-1. 見積書の案件No.
     手順: 新しく見積書を作成し、G54セルを確認
     期待: 「案件No.17-001」のように、見出し付きで入っている

[ ] 2-2. 見積書の見積書No.
     手順: 同じ見積書のG53セルを確認
     期待: 「見積書No.{通し番号}」の形式で入っている

[ ] 2-3. 見積書の留意点
     手順: 同じ見積書のJ49セルを確認
     期待: 取引先DBのP列「留意点」の内容がそのまま入っている

[ ] 2-4. 見積書の担当社員（変更なし）
     手順: G12・G13セルを確認
     期待: 担当社員の氏名とメールアドレスが入っている

[ ] 2-5. 見積書の自動転記セルが編集できないこと
     手順: G53・G54セルを編集してみる
     期待: 編集できない（ロックされている）

[ ] 2-6. 請求書の転記位置
     手順: 請求書を作成し、G54・G52・G11・G12・G53セルを確認
     期待: G54=案件No.、G52=請求書No.、G11=担当社員名、G12=メール、
           G53=見積書No.の参照

[ ] 2-7. 納品書の転記位置
     手順: 納品書を作成し、G54・G6・G11・G12・G52・G53セルを確認
     期待: G54=案件No.、G6=納品書の通し番号、G11=担当社員名、G12=メール、
           G52=見積書No.の参照、G53=請求書No.の参照

[ ] 2-8. 見積書No.の参照が二重にならないこと
     手順: 請求書のG53セル、納品書のG52セルを確認
     期待: 「見積書No.12」のように1回だけ。「見積書No.見積書No.12」の
           ような表示になっていない

[ ] 2-9. PDFに正しく出ること
     手順: 見積書・請求書・納品書のPDFを出力して確認
     期待: 案件No.・各No.が切れずに印字されている。J49（留意点）は
           PDFに出ていない

[ ] 2-10. 差分ハイライトが正しく動くこと
     手順: 請求書のG11（担当社員名）を書き換える
     期待: そのセルが黄色になる（見積書のG12と突き合わせています）
     補足: G52（請求書の通し番号）・G53（見積書No.）は請求書独自の項目の
           ため、黄色になりません

3. 取引先名のプルダウン（修正内容3）
==========================================================================

取引先DBには同じ社名で担当者だけが異なる行があるため、案件シートの
取引先名は「社名（担当者名）」の形式で選ぶ方式に変更しました。

準備: 取引先DBに、同じ社名で担当者が異なる行を2件用意しておく

[ ] 3-1. プルダウンから選べること
     手順: 表示シートのB列（取引先名）のセルを選択し、プルダウンを開く
     期待: 「株式会社ABC（山田太郎）」のような形式で選択肢が並ぶ

[ ] 3-2. 担当者違いを選び分けられること
     手順: 社名が重複している取引先の選択肢を確認
     期待: 担当者ごとに別々の選択肢として並んでいる

[ ] 3-3. 一覧に無い値を入力できないこと
     手順: B列に手入力で適当な社名を入れる
     期待: 入力規則で弾かれる

[ ] 3-4. 選んだ担当者の情報が転記されること
     手順: 社名が重複する取引先で案件を登録し、見積書を作成する
     期待: 宛先欄に、選んだ担当者の部署・担当者名・住所が入っている
           （社名の欄には社名だけが入り、担当者名は付かない）

[ ] 3-5. 新しい取引先が反映されること
     手順: 取引先登録フォームから1件登録 → メニュー「管理者用メニュー」→
           「取引先名の選択肢を更新する」
     期待: 追加した取引先がプルダウンに現れる

[ ] 3-6. 日次処理でも更新されること
     手順: 翌日、操作ログを確認する
     期待: 「取引先名の選択肢更新」の行が記録されている

[ ] 3-7. 社名だけの案件でエラーになること（想定どおりの動作）
     手順: 社名が重複している取引先について、B列へ社名だけを入力した状態で
           見積書を作成してみる
     期待: 「取引先を特定できません」というエラーが表示され、
           プルダウンから選び直すよう案内される

4. 既存機能の確認（デグレードが無いこと）
==========================================================================

[ ] 4-1. 通常の流れが一通り動くこと
     手順: 新規案件を1件登録し、見積書作成 → 完成 → 承認 → PDF出力 →
           請求書作成 → 完成 → 承認 → PDF出力 → 納品書作成 → PDF出力 →
           最終承認 まで実施
     期待: 各段階でエラーが出ず、ステータスが正しく遷移する

[ ] 4-2. 差し戻し・再作成が従来どおり動くこと
     手順: 見積書を差し戻し → 再作成 → 完成 → 承認
     期待: 従来どおり動作する

[ ] 4-3. 案件中止・復元が従来どおり動くこと
     手順: テスト案件を中止 → 全案件DBから「元に戻す」
     期待: 従来どおり動作する

[ ] 4-4. 終了予定・請求予定のプルダウンが従来どおり動くこと
     手順: D列・E列のプルダウンを開く
     期待: 従来どおり月の選択肢が並ぶ（今回の修正の影響を受けていない）

[ ] 4-5. 操作ログが記録されていること
     手順: 「操作ログ」シートを確認
     期待: 今回の一連の操作が記録されている。見積書の再作成の詳細欄に
           「請求書・納品書をロック（要再作成）」が残っている

5. 補足
==========================================================================

・案件シートのAK列「納品書無効化日時」は、システムが内部的に使う列です。
  見積書・請求書を作り直した時点で日時が入り、納品書を作り直すと空になります。
  手入力しないでください。

・見積書を作り直すと請求ステータスが「未請求」へ戻ります。請求書・納品書を
  作り直してPDF出力すると、再び「請求済み」になります。

・詳しい仕様は以下のドキュメントを参照してください。
    docs/仕様書_v2.4.docx
      第5章5.5「請求後の再見積もりフロー」
      第6章6.2「書類の自動転記項目」「6.2.1 書類共通の転記先セル」
      第6章6.10「取引先名の管理」
      第6章6.11「請求後の再見積もりと下流書類の無効化」
    docs/ユーザー用マニュアル_v2.4.docx
      第12章「請求後に見積もりをやり直す」
    docs/初期設定マニュアル_v2.4.docx
      3.3「入力規則（プルダウン）の設定」、5.1「転記先セルの配置」
